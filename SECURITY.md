# Security Policy

## Project status

ABYXO is an early-stage project concept. This repository does not currently establish that a token or production smart contract has been deployed, audited, or launched.

## Reporting a vulnerability

Please do not publish exploit instructions, private keys, seed phrases, credentials, or sensitive personal information in a public issue.

If GitHub's **Private vulnerability reporting** feature is enabled for this repository, use it to submit a report privately. If it is not available, open a minimal public issue titled **Request for a private security contact** without including technical exploit details. The maintainers can then indicate a safe reporting route.

Please include, where safe:
- The affected file, component, or commit.
- A concise description of the security impact.
- Reproduction steps that do not expose secrets or harm users.
- Any suggested mitigation.

## Scope and expectations

- Website and repository issues may be reported.
- Smart-contract security review is not complete merely because code exists in this repository.
- Do not test against systems or wallets you do not own or have permission to assess.
- No response time or remediation deadline is guaranteed at this early stage.

Thank you for helping keep the Abyxonauts community safer.
