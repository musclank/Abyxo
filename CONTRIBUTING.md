# Contributing to ABYXO

Welcome, Abyxonaut. Contributions that improve clarity, creativity, accessibility, and safety are appreciated.

## Before contributing

- Check existing files and open discussions to avoid duplicate work.
- Keep changes focused and explain their purpose.
- Use the ABYXO voice: playful, mischievous, community-minded, and transparent.
- Do not present draft plans, token details, partnerships, audits, or launch status as confirmed facts.

## Pull requests

Please include:
1. A short summary of the change.
2. The reason it is useful.
3. Screenshots for meaningful website or visual changes, where practical.
4. Any testing or manual checks performed.

For website changes, check desktop and mobile layouts and verify that referenced assets load correctly.

## Security and privacy

- Never commit seed phrases, private keys, passwords, API tokens, or personal data.
- Do not include exploit details in public issues; follow [SECURITY.md](SECURITY.md).
- Do not submit copied artwork, trademarks, or content unless you have permission to use them.

## Smart contracts

Contract contributions require particular care. Include tests and clear documentation. No contribution should be treated as audited or production-ready without an independent review and explicit project approval.

## Community conduct

Be respectful. Harassment, spam, impersonation, deceptive promotion, and guaranteed-return claims are not welcome.
